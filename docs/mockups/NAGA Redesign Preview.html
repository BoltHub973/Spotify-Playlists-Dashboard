01

Design Direction & Tokens

The app already speaks NAGA — Orbitron headers, neon green, album-color ambience. The redesign formalizes it: one token sheet instead of scattered hexes, a two-temperature accent system, and a third type role for data. Rajdhani stays for body; JetBrains Mono joins for counts, dates, and keycaps.

Two-Temperature Accents

Phosphor green stays the primary — active tiles, data, success. Cyan marks structure (dividers, edit mode). Amber is new: warnings, rate-limits, annotations. Spotify green is reserved exclusively for open-in-Spotify surfaces so the two greens never blur.

#84FF00 PHOSPHOR #00F3FF CYAN #FFB52B AMBER #1DB954 SPOTIFY #FF4D6D ERROR

Readability-First Type Scale

Track title grows to a real headline; playlist tile names get a floor of 16px at every window size (today they can clamp to 13.6px); secondary text ≥16px; mono metadata ≥14px. Line-height 1.5+ everywhere. Bigger fonts are the standing rule — the grid gains breathing room by tightening paddings, not shrinking words.
